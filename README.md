## 🥗 RotuScan

<div align="center">

<img src="https://capsule-render.vercel.app/api?type=rounded&height=100&text=ROTUSCAN&fontSize=35&fontColor=FFFFFF&animation=blinking&color=0:096446,50:16A34A,100:51CF3C"/>

</div>

### 🧠 O problema

Muitas pessoas precisam verificar cuidadosamente os ingredientes de produtos alimentícios por causa de **alergias, intolerâncias ou restrições alimentares**.

A leitura manual dos rótulos pode ser demorada e, dependendo da composição do produto, algumas informações podem ser difíceis de identificar.

### 💡 A solução

O **RotuScan** é uma aplicação desenvolvida para facilitar a análise de rótulos de alimentos.

A proposta é permitir que o usuário **capture ou envie uma imagem do rótulo**, faça a leitura das informações e receba uma análise dos ingredientes encontrados.

O sistema busca identificar possíveis riscos relacionados a:

* 🌾 Glúten
* 🥛 Lactose
* 🥜 Amendoim
* ⚠️ Outros ingredientes potencialmente relevantes

As informações são apresentadas de maneira **visual, simples e acessível**, utilizando indicadores de risco.

### 🔄 Fluxo da aplicação

```text
             📷
       Captura do rótulo
              │
              ▼
       🔎 Leitura / OCR
              │
              ▼
       🧹 Normalização
        dos ingredientes
              │
              ▼
       🧠 Análise dos dados
              │
              ▼
     ┌───────────────────┐
     │   Resultado        │
     │                    │
     │ 🟢 Seguro          │
     │ 🟡 Atenção         │
     │ 🔴 Possível risco  │
     └───────────────────┘
```

### ✨ Principais funcionalidades

| Funcionalidade        | Descrição                                     |
| --------------------- | --------------------------------------------- |
| 📷 Leitura de rótulos | Captura da embalagem para análise             |
| 🔎 OCR                | Extração de texto da imagem                   |
| 🧠 Análise            | Identificação de ingredientes relevantes      |
| 🚦 Indicador de risco | Resultado visual em níveis                    |
| 📚 Histórico          | Consulta de análises anteriores               |
| ♿ Acessibilidade      | Interface pensada para facilitar a leitura    |
| 📱 Mobile             | Experiência adaptada para dispositivos móveis |
